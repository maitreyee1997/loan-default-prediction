# Loan Default Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a loan applicant is likely to default or not using machine learning techniques.
It follows an end-to-end data science pipeline similar to real-world industry projects.

## 🧠 Problem Statement
Financial institutions face losses due to loan defaults.
This model helps in identifying high-risk applicants in advance.

## 🗂 Dataset
- Source: Kaggle (Credit Risk Dataset)
- Target Variable: `loan_status` (0 = Non-default, 1 = Default)

## 🔧 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- XGBoost
- Matplotlib, Seaborn
- Joblib

## ⚙️ Project Pipeline
1. Data Loading & EDA
2. Missing Value Treatment
3. Categorical Encoding
4. Feature Scaling
5. Model Training (Logistic Regression, Random Forest, XGBoost)
6. Cross Validation
7. Model Saving (Pickle)
8. Ready for API Deployment

## 🚀 Best Model
- **XGBoost Classifier**
- Accuracy: ~94%
- Recall (Default class): ~73%
